# AC-to-DC Converter – PCB Design

## Overview
This project involves the design and development of a Printed Circuit Board (PCB) for an AC-to-DC converter. The circuit is designed to convert alternating current (AC) into direct current (DC) through a power conversion stage.

## Project Highlights
- AC-to-DC power conversion circuit
- Schematic design and PCB layout
- Component placement and routing
- PCB design using KiCad

## Tools Used
- **KiCad** – Schematic capture and PCB layout

## Repository Contents
- `Schematic/` – Circuit schematic files
- `PCB/` – PCB layout and design files
- `Images/` – PCB design screenshots

## Project Status
PCB design project. Hardware testing and performance validation can be documented as they are completed.

---

**Note:** This project involves AC mains voltage, which can be hazardous. Testing should only be performed with appropriate isolation and safety precautions.
